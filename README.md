UNAB Shop es una aplicación móvil desarrollada en Kotlin cuyo objetivo es facilitar la gestión y venta de los productos oficiales de la Universidad Autónoma de Bucaramanga (UNAB).

Está dirigida al público general, permitiendo que tanto miembros de la comunidad universitaria como personas externas puedan explorar, comprar y conocer los artículos institucionales disponibles en la tienda virtual.

## Stack

Lenguaje: Kotlin

IDE: Android Studio

Arquitectura: MVVM (Model-View-ViewModel)

Base de datos: Room / SQLite

Interfaz de usuario: XML + Material Design Components

Navegación: Android Jetpack Navigation Component

Persistencia de datos: SharedPreferences

Gestor de dependencias: Gradle

Control de versiones: Git / GitHub

Pruebas y depuración: Android Emulator y Logcat
